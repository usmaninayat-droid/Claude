# events — entity events module block

> **What it is.** All **events generated by entities** (telematics / ops): Over Speeding, Harsh Braking,
> Idle Warning, Engine Off, Black Spot Alarm, Harsh Turning, Fuel Theft, Excess Idling… Backed by the DS
> `EventsView` + `EventDetailSheet`. Built from Figma `W2z46FvC6aOdzOHDc3rqD5` (node `4292-25771`); full
> spec in kb `02-frames-pipelines/11-events.md`.

## Anatomy — ✅ built
- **Hybrid View** (`EventsView`): a 2-row filter bar (Assets · Workforce · Date Range / Events ·
  Criticality · Zone · Location) + date-grouped **event cards** (icon tile per type + title + subtitle +
  time-ago + meta chips [vehicle · person · zone · location] + optional metric chip; **critical = red left
  border, warning = amber**) beside a **map** of event markers.
- **Expand on click**: the card expands inline → a 2-col details grid (Criticality · Status · Peak Speed ·
  Speed Limit · Duration · Distance Over Limit · Vehicle Type) + **View Details**. The map **highlights** the
  event (flyTo) and shows a **contextual chart widget** (Speed-over-time).
- **View Details** (`EventDetailSheet`): wide right sheet — header (id · Event · status + Change Status),
  field grid, a route map, a Speed-Over-Time chart, and a right-rail **Timeline** (DS `ActivityFeed`:
  system / status-change / comment / justification) with a comment composer.

## Adapt (props)
- `EventsView`: `events: EventItem[]` (id · type · title · subtitle · criticality · timeLabel · dateGroup ·
  vehicle · person · zone · location · metric? · position · status · details[] · speedSeries? · speedLimit?),
  `eventStyles?` (per-type icon+color), `onViewDetails`.
- `EventDetailSheet`: `event`, `route?`, `timeline: FeedEntry[]`, `statusOptions`, `onStatusChange`,
  `onComment`.

Brand = FAMS blue; green/amber/red only for genuine criticality/status.

## Compose
`type:'dashboard'`, `tabKind:'instance'` — tabs Hybrid View / List View / Map View. Splice `eventsBlock`
into the app; feed it the entity event stream. (List/Map tab variants currently mirror Hybrid — follow-on.)
